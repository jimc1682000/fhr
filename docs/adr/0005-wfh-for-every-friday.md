# 0005. 所有非國定假日的週五一律建議 WFH

- Status: Accepted
- Date: 2025-10-01

## Context

此版本預設週五可申請 WFH。舊邏輯只在週五「有打卡紀錄」時才建議 WFH；週五整天沒打卡的日子先被當成整日缺勤處理，沒有產生 WFH 建議，使用者得自己補。

## Decision

- 只要不是國定假日，週五一律產生 9 小時的整天 WFH 建議，不論有沒有打卡：整日缺勤的處理先判斷是否為週五，有打卡的週五在 `_analyze_single_workday()` 中也直接建議 WFH 並結束該日判斷。
- 之後進一步加上 `_add_monthly_wfh_issues()`：分析涵蓋到的月份，其所有週五都自動補上 WFH 建議，方便一次提前申請整月。

## Consequences

- 週五不再產生遲到、加班或整日請假建議；週五的實際加班須另外判斷。
- 國定假日的判斷正確與否直接影響 WFH 建議，假日資料載入失敗時會出現多餘的 WFH（見 0001、0008）。
- 自動補上的 WFH 讓增量模式下的 `issues` 幾乎永遠不為空，原本「沒有新問題就輸出狀態列」的判斷因此失效。分析器與 `csv_exporter` 改為排除自動補上的 WFH 後再判斷是否輸出狀態列；另一種在 CSV merge 時保留僅含 WFH 狀態列的修法（PR #39）未合併。
