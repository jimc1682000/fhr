# 0007. 遲到一律建議請假，忘刷卡保留給使用者手動使用

- Status: Accepted
- Date: 2026-03-20

## Context

早期規則以 10:30 為遲到門檻，並會自動拿「忘刷卡」額度抵銷短時間遲到（每月 2 次）。此版本改為預設：遲到門檻提前，忘刷卡視為每年只有 4 次的稀缺額度。自動抵銷會在使用者不知情時把一年份的額度用掉。

## Decision

- 採班表制：`schedule_start` 09:30、`schedule_end` 18:30；彈性上班 08:30 到 10:00，超過 10:00 才算遲到。
- 遲到時數從 09:30 起算到實際到班，無條件進位到整數小時，一律產生請假建議。
- 分析器不再自動以忘刷卡抵銷遲到；是否用忘刷卡由使用者自行判斷。`forget_punch_allowance_per_month` 等欄位保留但分析流程不使用。
- PR #41 補充兩條規則：
  - 遲到區間跨過 12:30–13:30 午休時，先扣掉午休重疊再進位。例如 13:00 到班，09:30 到 13:00 共 3.5 小時，扣掉 0.5 小時午休後為 3 小時，而不是 4 小時。
  - 平日整日缺勤（非週五）由 `analysis-v1` 匯出為 `type_hint="full_day"`（8 小時，09:30–18:30），之前這類缺勤從未進入送單流程。

## Consequences

- 所有遲到都會出現在請假清單；使用者若要改用忘刷卡，須自己在 Portal 申請並移除該筆請假。
- 規則值寫在 `AttendanceConfig` 預設值；repo 內附的 `config.json` 因鍵名不符而不會生效（見 0002），調整規則請改 dataclass 或使用小寫鍵名。
- 此決策直接在 main 提交，沒有對應 PR；日期取該提交日，PR #41 同步了文件。
